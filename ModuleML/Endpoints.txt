================================================================================
ЭНДПОИНТ: /filter
================================================================================

МЕТОД: POST

ОПИСАНИЕ:
  Фильтрация датасета по заданным условиям.
  Фильтрация может применяться к текущему датасету в памяти сервера.

================================================================================
ПАРАМЕТРЫ ЗАПРОСА (JSON):
================================================================================

{
    "filters": [                    // обязательный, массив условий фильтрации
        {
            "field": "string",      // обязательный, имя поля для фильтрации
            "operator": "string",   // обязательный, оператор сравнения
            "value": any            // обязательный, значение для сравнения
        }
    ],
    "replace": boolean              // необязательный, по умолчанию true
                                    // true  - заменяет текущий датасет отфильтрованным
                                    // false - возвращает отфильтрованные данные, но не заменяет
}

================================================================================
ОПЕРАТОРЫ ФИЛЬТРАЦИИ:
================================================================================

eq       - равно                      {"field": "city", "operator": "eq", "value": "Москва"}
ne       - не равно                    {"field": "city", "operator": "ne", "value": "Москва"}
gt       - больше                      {"field": "price", "operator": "gt", "value": 10000}
lt       - меньше                      {"field": "price", "operator": "lt", "value": 5000}
gte      - больше или равно            {"field": "price", "operator": "gte", "value": 10000}
lte      - меньше или равно            {"field": "price", "operator": "lte", "value": 5000}
contains - содержит подстроку          {"field": "city", "operator": "contains", "value": "Моск"}

================================================================================
ПРИМЕРЫ ЗАПРОСОВ:
================================================================================

1. Простая фильтрация по цене:
{
    "filters": [
        {"field": "lead_price", "operator": "gt", "value": 10000}
    ],
    "replace": true
}

2. Несколько условий:
{
    "filters": [
        {"field": "lead_price", "operator": "gt", "value": 10000},
        {"field": "contact_Город", "operator": "eq", "value": "Москва"},
        {"field": "buyout_flag", "operator": "eq", "value": true}
    ],
    "replace": true
}

3. Поиск по тексту:
{
    "filters": [
        {"field": "contact_Город", "operator": "contains", "value": "Моск"}
    ],
    "replace": false
}

4. Исключение значений:
{
    "filters": [
        {"field": "lead_Вид оплаты", "operator": "ne", "value": "Наложенный платеж"}
    ],
    "replace": true
}

================================================================================
ОТВЕТ (JSON):
================================================================================

ПРИ УСПЕШНОМ ВЫПОЛНЕНИИ (replace = true):

{
    "status": "success",
    "before_filtering": 17966,      // количество записей ДО фильтрации
    "after_filtering": 5320,         // количество записей ПОСЛЕ фильтрации
    "removed": 12646,                // количество удалённых записей
    "replace_original": true         // датасет заменён
}

ПРИ УСПЕШНОМ ВЫПОЛНЕНИИ (replace = false):

{
    "status": "success",
    "before_filtering": 17966,       // количество записей ДО фильтрации
    "after_filtering": 5320,         // количество записей ПОСЛЕ фильтрации
    "removed": 12646,                // количество удалённых записей
    "replace_original": false        // датасет НЕ заменён, только показан результат
}

ПРИ ОШИБКЕ:

{
    "detail": "Описание ошибки"
}

================================================================================
КОДЫ ОТВЕТОВ HTTP:
================================================================================

200 - Успех
400 - Ошибка в запросе (неверные параметры)
404 - Поле не найдено
500 - Внутренняя ошибка сервера
================================================================================

================================================================================
ЭНДПОИНТ: /query
================================================================================

МЕТОД: POST

ОПИСАНИЕ:
  Запрос данных с фильтрацией, сортировкой и пагинацией.
  Возвращает отфильтрованные данные без изменения основного датасета.

================================================================================
ПАРАМЕТРЫ ЗАПРОСА (JSON):
================================================================================

{
    "filters": [                    // необязательный, массив условий фильтрации
        {
            "field": "string",      // имя поля
            "operator": "string",   // оператор (eq, ne, gt, lt, gte, lte, contains)
            "value": any            // значение для сравнения
        }
    ],
    "sort": [                       // необязательный, массив условий сортировки
        {
            "field": "string",      // имя поля для сортировки
            "direction": "string"   // asc (по возрастанию) или desc (по убыванию)
        }
    ],
    "limit": 100,                   // необязательный, макс. кол-во записей (по умолч. 100)
    "offset": 0,                    // необязательный, смещение для пагинации (по умолч. 0)
    "fields": ["field1", "field2"]  // необязательный, список полей для возврата
}

================================================================================
ПРИМЕРЫ ЗАПРОСОВ:
================================================================================

1. Простая фильтрация:
{
    "filters": [
        {"field": "lead_price", "operator": "gt", "value": 10000}
    ],
    "limit": 50,
    "offset": 0
}

2. Фильтрация + сортировка:
{
    "filters": [
        {"field": "buyout_flag", "operator": "eq", "value": true}
    ],
    "sort": [
        {"field": "lead_price", "direction": "desc"}
    ],
    "limit": 100
}

3. Выбор конкретных полей:
{
    "filters": [
        {"field": "contact_Город", "operator": "eq", "value": "Москва"}
    ],
    "fields": ["lead_id", "lead_price", "contact_Город", "buyout_flag"],
    "limit": 20
}

4. Пагинация (вторая страница):
{
    "limit": 100,
    "offset": 100,
    "sort": [{"field": "lead_created_at", "direction": "desc"}]
}

================================================================================
ОТВЕТ (JSON):
================================================================================

{
    "status": "success",
    "total_count": 17966,           // общее количество записей, удовлетворяющих фильтрам
    "returned_count": 100,           // количество записей в ответе
    "data": [                        // массив записей
        {
            "lead_id": "LEAD_0001",
            "lead_price": 15000,
            "contact_Город": "Москва",
            "buyout_flag": true
        }
    ],
    "processing_time_ms": 12.34      // время выполнения запроса в миллисекундах
}

================================================================================
КОДЫ ОТВЕТОВ HTTP:
================================================================================

200 - Успех
400 - Ошибка в запросе
500 - Внутренняя ошибка сервера
================================================================================

================================================================================
ЭНДПОИНТ: /sort
================================================================================

МЕТОД: POST

ОПИСАНИЕ:
  Сортировка текущего датасета по указанному полю.
  Сортировка применяется к датасету в памяти сервера и заменяет его.

================================================================================
ПАРАМЕТРЫ ЗАПРОСА (JSON):
================================================================================

{
    "field": "string",              // обязательный, имя поля для сортировки
    "direction": "string"           // необязательный, asc или desc (по умолч. asc)
}

================================================================================
ПРИМЕРЫ ЗАПРОСОВ:
================================================================================

1. Сортировка по возрастанию:
{
    "field": "lead_price",
    "direction": "asc"
}

2. Сортировка по убыванию:
{
    "field": "lead_price",
    "direction": "desc"
}

3. Сортировка по дате (по умолчанию asc):
{
    "field": "lead_created_at"
}

================================================================================
ОТВЕТ (JSON):
================================================================================

ПРИ УСПЕШНОМ ВЫПОЛНЕНИИ:

{
    "status": "success",
    "message": "Отсортировано по 'lead_price' (desc)",
    "records": 17966                // количество записей в отсортированном датасете
}

ПРИ ОШИБКЕ:

{
    "detail": "Field 'unknown_field' not found"
}

================================================================================
КОДЫ ОТВЕТОВ HTTP:
================================================================================

200 - Успех
404 - Поле не найдено
500 - Внутренняя ошибка сервера
================================================================================
